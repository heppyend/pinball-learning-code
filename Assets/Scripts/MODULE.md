# Scripts 模块说明

## 职责

项目自有 C# 业务与基础代码根目录，包含应用根、通用工具、业务逻辑、网络/协议、配置表、热更新代码和编辑器工具。

## 子模块

- `Common`：跨模块通用辅助能力。
- `CSharp`：热更新、构建与其他 C# 代码。
- `Frame`：框架层代码。
- `GameLogic`：游戏业务逻辑。
- `NetWork`、`WebWork`：网络与协议相关代码。
- `Table`：配置/表格相关代码。
- `Editor`：仅编辑器运行的工具。

## 约束与验证

- 新业务按职责落入已有或新建领域目录；新目录必须同时创建 `MODULE.md`。
- 不在 UI 回调中复制货币、奖励、背包或导航状态机；优先复用共享服务。
- 编辑器代码只放入 `Editor` 或 Editor asmdef；修改程序集边界后验证 Unity 编译与热更新构建。

# Client UI 模块说明

## 职责

存放新非战斗客户端的页面视觉资源与页面实现。当前仅包含主页面；所有页面由 `ClientShell` 演示入口创建，不进入旧大厅或战斗场景。

## 资源策略

- `切图(11)/` 是负责人本次提供的独立素材源目录，保持原始页面和子目录层级，暂不覆盖现有页面素材，也不自动替换场景引用。后续按页面验收逐项替换到 `ClientShell`。
- 该目录当前作为原样导入资源目录维护；需要在 UI 中使用某张切图时，先在 Unity Import Settings 将其设为 `Sprite (2D and UI)`，再由场景 `Image` 或预制体引用。

- `MainPage/HomeReference.png` 来自负责人提供的 `D:\Users\Administrator\Desktop\UI\主页\参考.png`，只作为首版主页面的完整视觉构图。
- 当前主页面中央立绘没有独立切图，因此它暂时随参考构图整体显示；获得独立授权立绘后应替换为分层资源，不改变页面逻辑。
- 正式打包前须为本目录资源补充 YooAsset 收集规则、地址、分包与生命周期验证；本轮不改动既有收集器。

# BNRoom 模块说明

## 职责

现有弹珠战斗表现与房间相关逻辑目录，包含弹珠、敌人、伤害数字、特效收集等实现。

历史 Tiled 地图怪物生成脚本 `SinglePlayer/BNMonsterSpawnManager.cs` 已按负责人决定移除：目标小程序不使用该功能，且项目不再保留 SuperTiled2Unity 依赖。

## 约束与验证

- 当前交互稿未定义最终战斗玩法、关卡和数值；本目录的既有行为视为历史实现，不自动视为新产品规则。
- 修改前核对关联场景、预制体、资源地址和 `GameLogic` 调用；变更后至少验证一个战斗/效果演示路径。
- `UI/LobbyUI.cs` 的 WebGL Player 演示路径以本地战力占位替代英雄数据网络请求；非 WebGL 保持原请求。待确认大厅界面成功出现后再评估现有输入与交互覆盖范围。
